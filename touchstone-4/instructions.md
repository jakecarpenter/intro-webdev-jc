# Instructions

## Step 1: Choose Your Client

Review the Client Information Page. Select ONE client. Carefully read the client’s purpose, audience, content expectations, media expectations, and form requirements.

## Step 2: Plan Your Website Structure

Outline the content for four pages: index.html, products.html or services.html, about.html, and contact.html or events.html.

    *Decide where the required elements will appear, including relevant images, one figure with a caption, one responsive image using the <picture></picture> element, one audio or video element with fallback text, and the required form.
    *Media files will be provided. Plan how you will incorporate those assets in ways that support your selected client’s purpose and content.
    *Ensure your content decisions align with your selected client’s goals, audience, and tone.

## Step 3: Build Your HTML Pages

Create four separate HTML files in GitHub Codespaces using proper boilerplate structure.

    Include one h1 per page, along with header, nav, main, and footer elements.
    Build consistent navigation using an unordered list and relative paths.
    Add the required provided media and embed at least one audio or video element using HTML with fallback text.
    Include one complete form with proper labels, fieldset, legend, and built-in validation attributes.
    Do not include CSS or JavaScript in this Touchstone Task.

## Step 4: Review Your Work

Review each page in GitHub Codespaces and correct any errors.

    Confirm a logical heading hierarchy and meaningful alt text.
    Ensure all internal links function correctly.
    Verify that all required elements are included and properly structured.
    Make sure your content, media, and form choices match your selected client.

## Step 5: Prepare and Submit Your Document

Download and complete the provided student template document.

Common Mistakes to Avoid

    Using generic content that does not match the selected client
    Missing or vague alt text
    Forgetting fallback text for audio or video
    Using broken or incorrect relative links
    Leaving out required form elements such as labels, fieldset, or legend
    Submitting screenshots instead of pasting code as text

Your website should not only include the required HTML elements. It should also reflect the purpose, audience, and content needs of your selected client.
